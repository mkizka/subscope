# Webクライアントのデザインルール

UIライブラリを使わずに、どの画面も同じ見た目になるようにするためのルール。apps/web の画面はすべてこのルールに従って Tailwind CSS で書く。

## 基本の考え方

- 区切りは線で表し、影はほぼ使わない
- 角は丸くする。ボタンや入力欄は丸、箱は大きめの角丸にする
- 迷ったら新しい値を作らず、下の表にある値から選ぶ
- `text-[15px]` や `rounded-[14px]` のような任意値は使わない

## 色

- `apps/web/app/app.css` の色トークンだけを使う。Tailwind標準の色（`gray-500`、`red-600`、`white` など）は使わない
  - 例外として、ダイアログの背景の暗幕だけは `bg-black/40` を使う

| トークン     | 使う場所                                                     |
| ------------ | ------------------------------------------------------------ |
| `surface`    | 画面とダイアログの背景                                       |
| `surface-2`  | ホバー、選択中のメニュー、画像のない場所の仮置き（アバター） |
| `line`       | 区切り線、入力欄・枠ありボタンの枠                           |
| `ink`        | 本文、名前、見出し                                           |
| `muted`      | ハンドル、日時、件数、説明文などの補足                       |
| `brand`      | 主ボタン、いいね済み、選択中タブの下線、リンク               |
| `on-brand`   | `brand` と `danger` の上の文字                               |
| `brand-soft` | 未読の通知など、目立たせたい行の背景                         |
| `danger`     | 削除・BANなど取り消せない操作、エラーの文字                  |

## 文字

| 用途                           | クラス              |
| ------------------------------ | ------------------- |
| ページの見出し                 | `text-xl font-bold` |
| セクション・ダイアログの見出し | `text-lg font-bold` |
| スレッドで選んだ投稿の本文     | `text-lg`           |
| 投稿本文、名前、入力欄         | `text-base`         |
| 補足、ボタン、タブ、メニュー   | `text-sm`           |
| バッジ、注記                   | `text-xs`           |

- 太さは通常と `font-bold` の2つだけにする
- 補足の文字は `text-muted` にする
- 入力欄はiOSで拡大されないよう `text-base` 以上にする

## 余白

- 余白（padding、margin、gap）は `1`・`2`・`3`・`4`・`6`・`8` の段階だけを使う
- 一覧の行は `px-4 py-3`、アバターと本文の間は `gap-3` にする
- 行の中の要素どうしは `gap-2`、まとまったセクションの内側は `p-4` にする

## 角丸

| 形                                            | クラス         |
| --------------------------------------------- | -------------- |
| ボタン、1行の入力欄、検索欄、バッジ、アバター | `rounded-full` |
| カード、複数行の入力欄、画像、メニューの項目  | `rounded-xl`   |
| ダイアログ                                    | `rounded-2xl`  |

## 線と影

- 線は `border-line` の1pxだけを使う
- 一覧の行やセクションは `border-b border-line` で区切り、カードで囲まない
- 影は画面の上に浮く部品（メニュー、スマホの投稿ボタン）だけ `shadow-lg` を使う。ダイアログは暗幕で浮かせ、影は付けない

## 状態

- ホバー: 行・ゴーストボタン・メニュー項目は `hover:bg-surface-2`、塗りのボタンは `hover:opacity-90`
- フォーカス: `app.css` で全要素の `:focus-visible` に `brand` 色の輪郭線を付けているので、各部品では指定しない
- 無効: `disabled:opacity-50 disabled:cursor-not-allowed`
- 選択中: メニューは `bg-surface-2 font-bold`、タブは `font-bold text-ink` と `brand` の下線、選ばれていないタブは `text-muted`
- 送信中: ボタンを無効にし、ラベルの前に lucide の `LoaderCircle` を `animate-spin` で出す
- エラー: 入力欄の下に `text-sm text-danger` で出す
- 空の一覧: `py-8 text-center text-sm text-muted` の1文を出す

## 基本部品

繰り返し使う部品は `apps/web/app/components/ui/` に置き、画面ではこれを使う。同じ見た目をその場のクラスで作り直さない。

| 部品       | ファイル        | 内容                                                                                                      |
| ---------- | --------------- | --------------------------------------------------------------------------------------------------------- |
| `Button`   | `button.tsx`    | 種類は `primary`（塗り）、`outline`（枠）、`ghost`（枠なし）、`danger`。リンクには `buttonClass()` を使う |
| `Dialog`   | `dialog.tsx`    | `<dialog>` で作るダイアログ。暗幕のクリックで閉じる                                                       |
| `LinkTabs` | `link-tabs.tsx` | URLで切り替えるタブ                                                                                       |
| `Avatar`   | `avatar.tsx`    | 丸いアバター。画像がないときは `bg-surface-2`                                                             |
| `Input`    | `input.tsx`     | 1行の入力欄と複数行の入力欄（`Textarea`）                                                                 |

- 部品の置き場所
  - 2つ以上のfeatureで使う部品は `components/ui/` に置く
  - 1つのfeatureだけで使う部品は `features/{feature}/parts/` に置く
- 新しい基本部品を足すときは、この表に行を足す
- チェックボックス・ラジオ・セレクトはブラウザ標準の要素を使い、色は `app.css` の `accent-color` で `brand` にそろえる
- アイコンは lucide-react を使い、ボタンの中では `size-4`、ナビでは `size-6` にする
