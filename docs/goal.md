# プロジェクトのゴール

## v1.0 完成の定義

次の3つを満たしたら v1.0 とする。

| ゴール                              | 内容                                                                                                                |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| セルフホストできる                  | 4コア・4GB RAM・100GB ストレージ程度の VPS に Docker Compose でデプロイでき、[デプロイ手順](./user/deploy.md)がある |
| Web クライアントで SNS として使える | Bluesky クライアント相当の[機能](#v10-の-web-クライアントの機能)がある                                              |
| 管理者が Web 画面から運用できる     | 招待コードとメンバーを[管理画面](./specs/web/admin.md)で管理できる                                                  |

## v1.0 の Web クライアントの機能

| 分類               | 機能                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| 認証・登録         | OAuth でのログイン・ログアウト、招待コードでのメンバー登録                                             |
| タイムライン・投稿 | ホームタイムライン、投稿の作成（テキスト、画像、リプライ、引用）と削除、いいね、リポスト、スレッド表示 |
| ユーザー           | プロフィール（投稿、リプライ、メディア、いいね）、フォロー、フォロー一覧、フォロワー一覧               |
| 通知               | 通知一覧（いいね、リポスト、リプライ、引用、メンション、フォロー）、未読数、既読化                     |
| 検索               | 投稿とユーザーの検索                                                                                   |
| リスト             | リストの一覧・詳細・フィード、リストとメンバーの編集                                                   |
| 管理画面           | [管理画面の仕様](./specs/web/admin.md)の機能                                                           |

## v1.0 の対象外

カスタムフィード、ブロック・ミュート、DM、スターターパックは v1.0 に入れない。
