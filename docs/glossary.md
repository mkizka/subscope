# 用語

仕様書・画面・コードで同じ語を使う。表の「使わない語」は同じものを指す別名で、使わない。

| 用語             | 意味                                                                                                                          | コード              | 使わない語                               |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------- | ---------------------------------------- |
| サーバー         | 設置したSubscope全体(web・appview・worker)。AppViewはappviewだけを指す                                                        | -                   | -                                        |
| アカウント       | atprotoのアカウント(DID)                                                                                                      | `account`           | アクター、ユーザー                       |
| 登録             | アカウントが招待コードでサーバーに登録すること                                                                                | `registration`      | サブスクライブ                           |
| 登録アカウント   | 登録したアカウント                                                                                                            | `registeredAccount` | サブスクライバー、メンバー、登録ユーザー |
| フォロー先       | 登録アカウントがフォローしているアカウント                                                                                    | `followee`          | フォロイー                               |
| 追跡             | サーバーがアカウントをTapに追加し、そのレコードを受け取り続けること                                                           | `track`             | -                                        |
| 追跡アカウント   | 登録アカウントとそのフォロー先                                                                                                | `trackedAccount`    | 追跡アクター、追跡中のユーザー           |
| 招待コード       | サーバーが発行し、登録時に指定するコード。形式は`{サーバーのドメインをケバブケースにした文字列}-{ランダムな5文字}`            | `inviteCode`        | -                                        |
| 管理者           | 管理画面を使える登録アカウント。最初にログインしたアカウントがなる                                                            | `isAdmin`           | -                                        |
| BAN              | 管理者が登録アカウントの登録を解除し、再登録できなくすること                                                                  | `ban`               | -                                        |
| 閲覧者           | XRPCを認証付きで呼んだアカウント                                                                                              | `viewer`            | -                                        |
| アカウントの状態 | active・deactivated・deleted・suspended・takendown のいずれか                                                                 | `status`            | 退会済み                                 |
| バックフィル     | 追跡アカウントの過去のレコードをTapから受け取ること。画面では「同期」と呼び、状態を「同期中」「同期済み」「同期エラー」と出す | `backfillStatus`    | 取り込み                                 |

Tapに対しては「登録」ではなく「追加する」「外す」と書く。

画面の文言のうち、Blueskyの公式クライアントに合わせたもの(検索の「ユーザー」タブなど)はそのままにする。
