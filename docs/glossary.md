# 用語

仕様書・画面・コードで同じ語を使う。「使わない語」は同じものを指す別名なので使わない。

| 用語                         | 意味                                                                                                     | 使わない語                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| サーバー                     | 設置したSubscope全体(web・appview・worker)。AppViewはappviewだけを指す                                   | -                                              |
| アカウント                   | atprotoのアカウント(DID)                                                                                 | アクター、ユーザー                             |
| 登録                         | アカウントが招待コードでサーバーに登録すること                                                           | サブスクライブ                                 |
| メンバー                     | 招待コードでサーバーに登録したアカウント                                                                 | 登録アカウント、サブスクライバー、登録ユーザー |
| フォロー先                   | あるアカウントがフォローしているアカウント。誰のフォローかは問わない                                     | フォロイー                                     |
| フォローされているアカウント | メンバーの誰かにフォローされているアカウント。メンバーも含む。画面では「誰かがフォロー」と呼ぶ           | -                                              |
| 追跡                         | サーバーがメンバー以外のアカウントの新しいレコードを、Jetstreamから受け取り続けること                    | -                                              |
| 追跡アカウント               | フォローされているアカウントのうち、メンバーでないもの                                                   | 追跡アクター、追跡中のユーザー                 |
| 宛先                         | レコードが向けられたアカウント。返信先・起点・引用元の作者、メンション・いいね・リポスト・フォローの相手 | -                                              |
| 招待コード                   | サーバーが発行し、登録時に入力するコード。サーバーのドメインとランダムな5文字からなる                    | -                                              |
| 管理者                       | 管理画面を使えるメンバー                                                                                 | -                                              |
| 閲覧者                       | XRPCを認証付きで呼んだアカウント                                                                         | -                                              |
| アカウントの状態             | active・deactivated・deleted・suspended・takendown のいずれか                                            | 退会済み                                       |
| バックフィル                 | メンバーの過去のレコードをTapから受け取ること。画面では「同期」と呼ぶ                                    | 取り込み                                       |

コードでは、登録を register・registration、メンバーを member、追跡アカウントを tracked、宛先を addressee と書く。メンバーを registered と呼ばない。

Tapに対しては「登録」ではなく「追加する」「外す」と書く。

Blueskyの公式クライアントに合わせた画面の文言(検索の「ユーザー」タブなど)は、そのままにする。
