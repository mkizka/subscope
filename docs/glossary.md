# 用語

- サブスクライバー
  - AppViewに登録したアカウント
  - 変数名の例：`subscriber`
- 追跡アクター
  - サブスクライバーまたはサブスクライバーのフォロイー
  - 変数名の例：`trackedActor`
- 招待コード
  - AppViewが発行し、サブスクライバー登録時に指定する
  - 形式は`{AppViewドメインをケバブケースにした文字列}-{ランダムな5文字}`
  - 変数名の例：`inviteCode`
- バックフィル
  - 追跡アクターの過去のレコードをTapから受け取ること
  - UIでは「同期」と呼び、状態を「同期中」「同期済み」「同期エラー」と表示する
  - 変数名の例：`backfillStatus`
