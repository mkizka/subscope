# AppView仕様: ビューの共通ルール

## テイクダウン

モデレーションサービスがテイクダウンしたアカウントや投稿と、PDSで停止されたアカウントを、応答から隠す。データは消さないので、ラベルが取り消されたりアカウントが再開されたりすれば元に戻る。

| ID         | 仕様                                                                      |
| ---------- | ------------------------------------------------------------------------- |
| takedown-1 | !takedown か !suspend のラベルが付いたアカウントと投稿は応答に含めない    |
| takedown-2 | テイクダウンされたアカウントの投稿は応答に含めない                        |
| takedown-3 | 期限が切れたラベルは無視する                                              |
| takedown-4 | PDSでテイクダウン・停止・無効化されたアカウントとその投稿は応答に含めない |

## ラベル

プロフィールと投稿のビューのlabelsに、モデレーションサービスのラベルと、作成者がレコードに付けたセルフラベルを載せる。公式クライアントはこれを見て警告やぼかしを出す。

| ID       | 仕様                                                               |
| -------- | ------------------------------------------------------------------ |
| labels-1 | プロフィールのlabelsに、アカウントのDIDに付いたラベルを含める      |
| labels-2 | 投稿のlabelsに、投稿に付いたラベルを含める                         |
| labels-3 | プロフィールのlabelsに、プロフィールレコードに付いたラベルを含める |
| labels-4 | プロフィールのlabelsに、プロフィールレコードのセルフラベルを含める |
| labels-5 | 投稿のlabelsに、投稿レコードのセルフラベルを含める                 |
| labels-6 | 引用された投稿のlabelsにも、その投稿に付いたラベルを含める         |

セルフラベルは、レコードの作成者を付けた人、レコードを付けた先、レコードの作成日時を付けた日時としたラベルとして返す。

## ラベラーの指定

クライアントが atproto-accept-labelers ヘッダーで指定したラベラーのラベルだけをlabelsに載せる。公式クライアントは、アカウントが登録したラベラーをこのヘッダーで送る。対応しているのはgetPostsだけ。

| ID         | 仕様                                                                 |
| ---------- | -------------------------------------------------------------------- |
| labelers-1 | labelsには、指定されたラベラーのラベルだけを含める                   |
| labelers-2 | ヘッダーがないか不正なときは、すべてのラベラーのラベルを含める       |
| labelers-3 | 指定されたラベラーを、応答の atproto-content-labelers ヘッダーで返す |
| labelers-4 | テイクダウンは、指定されていないラベラーのラベルでも適用する         |

ヘッダーのredactの指定は応答のヘッダーにそのまま返すだけで、テイクダウンには使わない。

## atproto-repo-revヘッダー

ログイン中の本人のリポジトリのrevを返す。PDSはこのrevより新しい本人のレコードを応答に足し、投稿した直後でも表示に出るようにする。対応しているのはgetProfile、getProfiles、getTimeline、getListFeed、getPostThread、getAuthorFeed、getActorLikes。

| ID              | 仕様                                                            |
| --------------- | --------------------------------------------------------------- |
| repoRevHeader-1 | ログイン中なら、本人のrevを応答のatproto-repo-revヘッダーで返す |
| repoRevHeader-2 | revを記録していないときは、ヘッダーを付けない                   |
| repoRevHeader-3 | getPostThreadは、投稿が見つからないエラーでもヘッダーを返す     |

## 返信制限

スレッドの起点の投稿者がthreadgateで決めた「返信できる人」を、投稿のビューに反映する。

| ID            | 仕様                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------- |
| threadgate-1  | 起点の投稿のビューにthreadgateを含める                                                             |
| threadgate-2  | 返信を許されていない閲覧者には、replyDisabledをtrueにする                                          |
| threadgate-3  | 起点の投稿者と、メンション・フォロー・フォロワーの規則に合う閲覧者には、replyDisabledをfalseにする |
| threadgate-4  | 規則が無いthreadgateでは、replyDisabledをfalseにする                                               |
| threadgate-5  | リストの規則のリストに入っている閲覧者には、replyDisabledをfalseにする                             |
| threadgate-6  | リストの規則のリストのうちインデックスしたものを、threadgateのlistsに含める                        |
| threadgate-7  | 返信制限に違反した返信は、すべての閲覧者のreplyDisabledをtrueにする                                |
| threadgate-8  | 返信制限に違反した返信は、スレッドのリプライに含めない                                             |
| threadgate-9  | 返信制限に違反した返信をスレッドの中心にしたときは、親投稿とリプライを含めない                     |
| threadgate-10 | 返信制限に違反した返信のfeedViewPostには、replyを含めない                                          |

リストに入っているかは、インデックスしたリストの項目で判定する。

返信制限に違反した返信は、制限を無視するクライアントから送られた返信で、保存した時点で判定する。公式AppViewと同じく、スレッドの表示から外して返信の制限に効き目を持たせる。

## 引用制限

投稿者がpostgateで決めた引用の禁止と切り離しを、投稿のビューに反映する。

| ID         | 仕様                                                                    |
| ---------- | ----------------------------------------------------------------------- |
| postgate-1 | 引用を禁止した投稿は、投稿者以外の閲覧者のembeddingDisabledをtrueにする |
| postgate-2 | 引用された側が切り離した引用は、viewDetachedにする                      |
| postgate-3 | 引用禁止に違反した引用は、viewDetachedにする                            |

## 埋め込み

投稿に埋め込まれた画像・動画・リンクカード・引用を、公式AppViewと同じ形で返す。

| ID      | 仕様                                                                    |
| ------- | ----------------------------------------------------------------------- |
| embed-1 | 画像のギャラリーは、引用に添えたものも含めてgalleryのビューで返す       |
| embed-2 | 動画は、再生用のプレイリストとサムネイルをvideo.bsky.appのURLにして返す |

## フォロー状態

閲覧者がフォローしているアカウントには、どのAPIでも同じようにviewer.followingを返す。投稿の作成者やフィードジェネレーターの作成者も同じ。

| ID                | 仕様                                                                                    |
| ----------------- | --------------------------------------------------------------------------------------- |
| viewerFollowing-1 | 閲覧者がフォローしているアカウントのビューには、viewer.followingにフォローのURIを含める |

## フィード

getTimeline、getAuthorFeed、getActorLikes、getListFeedは、投稿をfeedViewPostで返す。

| ID             | 仕様                                                       |
| -------------- | ---------------------------------------------------------- |
| feedViewPost-1 | リプライには、スレッドの起点と親の投稿をreplyに含める      |
| feedViewPost-2 | 起点や親が見つからないときは、その投稿をnotFoundPostにする |
| feedViewPost-3 | リポストには、リポストしたアカウントと日時をreasonに含める |
