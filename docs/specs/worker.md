# worker仕様

## Tapへの登録

[追跡アクター](./record-indexing.md)だけをTapに登録する。登録状態が変わりうる操作のあとに`syncTapRepo`ジョブを積み、ジョブを実行した時点のDBの状態から登録するか削除するかを決める。

- syncTapRepo-1: サブスクライバーがフォローしたアカウントをTapに登録する
- syncTapRepo-2: サブスクライバーでないアカウントのフォローでは、フォロイーをTapに登録しない
- syncTapRepo-3: サブスクライバーがフォローを解除したアカウントは、追跡アクターでなくなればTapから削除する
- syncTapRepo-4: 他のサブスクライバーにもフォローされているアカウントは、フォローを解除されてもTapから削除しない
- syncTapRepo-5: サブスクライバーは、フォローを解除されてもTapから削除しない
