# Worker仕様: 通知

## 通知の生成

レコードをインデックスするときに、メンバー宛ての通知を作る。

| ID        | 仕様                                                                                                      |
| --------- | --------------------------------------------------------------------------------------------------------- |
| notify-1  | 通知はメンバー宛てにだけ作る                                                                              |
| notify-2  | 自分自身の操作では通知を作らない                                                                          |
| notify-3  | いいねされた投稿の作者に like の通知を作る                                                                |
| notify-4  | リポストされた投稿の作者に repost の通知を作る                                                            |
| notify-5  | フォローされたアカウントに follow の通知を作る                                                            |
| notify-6  | リプライの親投稿から4つ上までの投稿の作者に reply の通知を作る                                            |
| notify-7  | 引用された投稿の作者に quote の、メンションされたアカウントに mention の通知を作る                        |
| notify-8  | 1つの投稿から同じ相手への通知は mention、quote、reply の優先順で1件にする                                 |
| notify-9  | 通知はTapからリアルタイムに受け取ったレコードでだけ作り、バックフィルや取得しに行ったレコードでは作らない |
| notify-10 | 引用禁止に違反した引用では quote の通知を作らない                                                         |

リプライの祖先は保存済みの投稿だけをたどるので、未保存の投稿より上の作者には通知しない。

v1.0では、追跡アカウント以外からの通知（Tapから受信しないため）と、上記以外の種類（starterpack-joined、verified、like-via-repost、subscribed-post など）は作らない。

## プッシュ通知の送信

通知を作ったときに、受け取るメンバーが登録した端末へ Web Push でプッシュ通知をジョブで送る。設計は[プッシュ通知の設計](../../dev/push-notification.md)を参照する。

| ID     | 仕様                                                                            |
| ------ | ------------------------------------------------------------------------------- |
| push-1 | 送る前に取り消された通知は送らない                                              |
| push-2 | タイトルと本文を、通知の種類に合わせて設計書の表のとおりにする                  |
| push-3 | いいねとリポストは、同じ投稿への同じ種類の通知が端末上で1件にまとまるようにする |
| push-4 | プッシュサーバーが404か410を返した端末の登録を削除する                          |
| push-5 | 通知を新しく作ると、受け取るメンバーが登録したすべての端末に送る                |
| push-6 | すでに保存していた通知は、レコードの更新や再受信で作り直しても送らない          |
