# Worker仕様: 統計

## 統計の集計

いいね数やフォロワー数などの統計を、レコードのインデックス後にジョブで数え直す。ジョブは10秒遅らせて実行し、続けて来たイベントを1回にまとめる。

| ID          | 仕様                                                                                      |
| ----------- | ----------------------------------------------------------------------------------------- |
| aggregate-1 | 同じ対象のジョブが実行待ちの間に来たイベントは、そのジョブにまとめる                      |
| aggregate-2 | ジョブの実行中や完了後に来たイベントは、もう一度集計する                                  |
| aggregate-3 | 投稿のジョブが実行待ちの間に来た別の投稿のイベントも、そのジョブにまとめる                |
| aggregate-4 | アカウントのジョブは、フォロー・フォロワー・投稿のどのイベントから積まれても1つにまとめる |

バックフィルではいいねやリポストが多くの投稿に散らばって届くため、投稿の統計は投稿ごとにジョブを積まず、まとめて数え直す。
