# 管理画面仕様

管理者がサーバーを運用するための画面の振る舞いを定める。

管理者は、サーバーに最初にログインしたアカウントとする（[login-1](./web-e2e.md)）。登録ユーザーの一覧は全員が見られる「メンバー」（[UI仕様](./web-ui.md)）で見るため、管理画面には置かない。

## 管理画面へのアクセス

管理画面はログイン後の3カラムレイアウトの中央カラムに出す。

- admin-1: 左カラムの「サーバー」に、管理者にだけ「招待コード」と「ジョブキュー」を出す
- admin-2: 管理者でないアカウントが管理画面のURLを開くと403エラーを出す

## 招待コード

`/admin/invite-codes` で招待コードを管理する。

- invite-codes-1: 招待コードを新しい順に並べ、コード・状態（未使用・使用済み・期限切れ）・使用者・有効期限・作成日を出す
- invite-codes-2: 一覧の下までスクロールすると続きを読み込む
- invite-codes-3: 「新規作成」で有効期限7日の招待コードを作り、一覧の先頭に出す
- invite-codes-4: 未使用の招待コードだけを削除でき、期限切れでないものは削除前に確認する

## ジョブキュー

`/admin/bull-board` で bull-board の画面を3カラムレイアウトの外にそのまま出す。
