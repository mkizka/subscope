# Webクライアント UI仕様

## 方針

- チャットツール（Slack / Discord）の画面構成を土台に、SNSとして使いやすく調整する
- Bluesky公式クライアントのクローンに見えないようにする
- 「招待制の自分のサーバー」であることを前に出す

## レイアウト（PC）

3カラム構成とする。

| カラム | 内容                                                                                     |
| ------ | ---------------------------------------------------------------------------------------- |
| 左     | サーバー名と人数、タイムライン・リスト・サーバー・検索・プロフィールへの移動             |
| 中央   | 左で選んだもの（タイムライン、一覧、プロフィール全体ページなど）                         |
| 右     | 普段は通知。投稿を選ぶとスレッド、名前を選ぶとプロフィールの簡易表示。閉じると通知に戻る |

左カラムの項目

- タイムライン
  - フォロー中
  - ローカル
- リスト（自分のリスト、リストの作成）
- サーバー
  - メンバー
  - 追跡中のユーザー
- 検索、プロフィール
- 自分のアカウント（設定、ログアウト）

カスタムフィードは扱わない。

ログイン後の画面は `apps/web/app/components/three-column-layout.tsx` で3カラムに並べる。

## レイアウト（モバイル）

- 中央のタイムラインを基本画面とする
- 左カラムはヘッダーの ☰ から開くドロワー
- 通知はヘッダーの 🔔 から全画面で開く
- スレッドとプロフィールはタップで全画面に開く

## タイムライン

- 新しい投稿を下に並べる
- 開くと最新の投稿を表示し、上にスクロールすると古い投稿を読み込む
- 未読箇所からの再開はv1では扱わない
  - `app.bsky.feed.getTimeline` のcursorは指定日時より古い投稿しか返せないため
- 投稿欄は中央カラムの下に1行で畳んでおき、クリックで広げる
  - 広げると複数行の入力、文字数（300字）、画像（4枚まで）とALT、返信できる人の設定を出す

## 投稿の表示

- 同じ人の連続投稿もまとめず、1投稿ずつ名前とハンドルを出す
- 返信・リポスト・引用・いいねはホバーで出るツールバーから操作する
- いいね数・リポスト数は1以上のときだけチップで出す
- リプライはタイムラインに出さず、親投稿の「n件の返信」にまとめて右カラムのスレッドで開く
- リポストは投稿の上に「○○がリポスト」と出す
- 引用は投稿内の引用ブロック、リンクはカードで出す

## ローカルタイムライン

- サーバーのメンバー全員の投稿を流す
- リプライ・リポストの扱いはフォロー中のタイムラインと同じ

## メンバー・追跡中のユーザー

- メンバー：このサーバーのサブスクライバーの一覧
- 追跡中のユーザー：サブスクライバーとそのフォロイー（[追跡アクター](./record-indexing.md)）の一覧
  - 各ユーザーに、フォローしているメンバーを添える
  - フォローしているメンバーが多い順に並べる
- どちらも中央カラムに一覧を出し、名前・ハンドルで絞り込める

## プロフィール

- 右カラムの簡易表示から、中央カラムの全体ページ（投稿、リプライ、メディア、いいねのタブ）に移動する

## デザイン

- daisyUIのカスタムテーマを使い、ライト・ダークの両方を用意する
- 土台は白黒（墨）とし、ボタン・サーバー名・自分の操作にだけアクセント色を1色使う
- アクセント色はBluesky（青）、Mastodon（青紫）、Misskey（黄緑）と被らない色にする
  - 色はアイコンと合わせて決め、テーマの `primary` だけを差し替える
- テーマは `apps/web/app/app.css` で daisyUI の `light` / `dark` を上書きして定義し、OSの設定で切り替える
  - 現在の `primary` はアクセント色が決まるまでの仮の色（オレンジ）
- shadcn/ui から daisyUI へ移行中。ホーム・ログイン・登録画面は移行済み

## 必要なバックエンドの追加

ログイン中のサブスクライバーが使える独自APIとして追加する。名前は仮。

- `me.subsco.feed.getLocalTimeline` - ローカルタイムライン
- `me.subsco.server.getMembers` - メンバー一覧
- `me.subsco.server.getTrackedActors` - 追跡中のユーザー一覧（フォローしているメンバーを含む）
