# Web仕様: 検索

## 検索

`/search` で、このサーバーが保存しているアカウント（追跡アカウント）と投稿を探す。結果は「投稿」「ユーザー」タブで切り替え、最初は「投稿」を出す。検索語は `/search?q=検索語` で開ける。タブの切り替えではURLを変えない。

| ID         | 仕様                                                                             |
| ---------- | -------------------------------------------------------------------------------- |
| search-e1  | ユーザータブでは、表示名かハンドルが検索語に部分一致するアカウントを一覧表示する |
| search-e2  | 一覧のアカウントを選ぶと、そのアカウントのプロフィールに移動する                 |
| search-s1  | 一致するアカウントがないときは「ユーザーが見つかりません」と表示する             |
| search-s2  | URLに検索語があると、それを検索欄に入れて投稿タブの結果を表示する                |
| search-e3  | 投稿タブでは、本文が検索語に部分一致する投稿をリプライを除いて新しい順に表示する |
| search-s3  | 一致する投稿がないときは「投稿が見つかりません」と表示する                       |
| search-s7  | 検索語がないときは、探せる対象（追跡アカウントと投稿）の説明を出す               |
| search-s11 | 検索を実行すると、検索履歴を閉じる                                               |

投稿は最初の25件までを表示する。検索履歴は[共通](./common.md#検索履歴)で定める。
