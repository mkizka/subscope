# Web仕様: 検索

## 検索

中央カラムの `/search` で、上の検索欄に入力した語でアカウントと投稿を探す。検索欄の下の「投稿」「ユーザー」タブで結果を切り替える（最初は「投稿」）。検索語はURLの `?q=` に、ユーザータブは `?tab=accounts` に入れる。探せるのはこのサーバーが保存しているアカウント（追跡アカウント）と投稿だけ。

- search-e1: 左カラムの「検索」から開いた検索欄でユーザータブに切り替えて検索すると、表示名またはハンドルが検索語に部分一致するアカウント（名前、ハンドル、自己紹介）を一覧表示する
- search-e2: 一覧のアカウントを選ぶと、そのアカウントのプロフィール全体ページに移動する
- search-s1: 一致するアカウントがないときは「ユーザーが見つかりません」と表示する
- search-s2: URLに `?q=検索語` があると、検索欄にその語を入れて、投稿タブで検索結果を表示する
- search-e3: 投稿タブ（最初に表示されるタブ）で検索すると、本文が検索語に部分一致する投稿を、リプライを除いて新しい順に一覧表示する
- search-s3: 一致する投稿がないときは「投稿が見つかりません」と表示する
- search-s4: 検索ボタンは検索結果を読み込み終えるまでスピナーを出して押せなくする
- search-s5: アカウントの検索結果には過去の投稿の同期状態を表示する
- search-s6: 検索結果のページを開くと、結果の読み込みを待たずに画面を表示し、読み込み終えるまでスケルトンを表示する
- search-e4: 一度表示した検索結果に戻ると、読み込み直しを待たずに前回の結果を表示する
- search-s7: 検索語がないときは、検索欄の下に探せる対象（追跡アカウントと投稿）の説明を出す
- search-s11: 検索を実行すると、検索履歴（[共通](./common.md#検索履歴)）を閉じる

投稿の一覧は最初に読み込む25件までを表示する。
