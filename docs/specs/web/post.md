# Web仕様: 投稿

## 投稿欄

新規投稿ボタンや、投稿の返信・引用ボタンからモーダルで開き、本文・画像・ALT・返信できる人を入力する。

| ID           | 仕様                                                                                    |
| ------------ | --------------------------------------------------------------------------------------- |
| postForm-e1  | 投稿すると投稿欄を閉じ、再読み込みなしでタイムラインの一番上に表示する                  |
| postForm-s1  | 300字を超えると投稿できない                                                             |
| postForm-e2  | 画像にALTを付けて添付でき、タイムラインにALT付きで表示する                              |
| postForm-s2  | 画像は4枚まで添付できる                                                                 |
| postForm-e3  | 返信できる人の設定は、投稿と同じrkeyのthreadgateに保存する                              |
| postForm-e4  | 本文のURLとハッシュタグにfacetsを付ける                                                 |
| postForm-s3  | 入力欄に自分のアイコン・名前・ハンドルを添える                                          |
| postForm-s4  | 返信では、返信先の投稿を上に表示し、投稿ボタンを「返信」にする                          |
| postForm-s5  | 引用では、引用先の投稿を入力欄の下に枠で囲んで表示する                                  |
| postForm-s6  | 返信できる人は、入力欄の下の今の設定を示すボタンから選ぶ                                |
| postForm-s7  | 返信では、返信できる人の設定を表示しない                                                |
| postForm-s8  | モバイルでは、キーボードで隠れないよう投稿欄を画面の上寄せで開く                        |
| postForm-e5  | 添付した画像の縦横比をaspectRatioに保存する                                             |
| postForm-s9  | 画像に「+ ALT」(入力済みなら「ALT」)のバッジを重ね、押すとALTを入力するダイアログを開く |
| postForm-s10 | ALTは2000字を超えると保存できない                                                       |

返信できる人は公式クライアントと同じく、「誰でも」「返信不可」か、「フォロワー」「フォロー中」「メンションした人」の組み合わせから選ぶ。threadgateはスレッドの起点にしか効かないため、返信では選ばせない。

メンションはハンドルの解決が要るため、まだfacetsを付けない。

投稿はTap経由で遅れてインデックスされるため、appviewで見えるまで1秒おきに5回まで待ってから画面を更新する。

## 投稿のツールバー

投稿の下に、返信・リポスト・引用・いいねのボタンと「…」メニューを表示する。返信・リポスト・いいねには件数を並べる。

| ID              | 仕様                                                                                   |
| --------------- | -------------------------------------------------------------------------------------- |
| postToolbar-e1  | いいねボタンでいいねし、もう一度押すと取り消す                                         |
| postToolbar-e2  | リポストボタンでリポストし、もう一度押すと取り消す                                     |
| postToolbar-e3  | 返信ボタンで投稿欄を開き、その投稿への返信を投稿する                                   |
| postToolbar-e4  | 引用ボタンで投稿欄を開き、その投稿を引用した投稿をする                                 |
| postToolbar-e5  | いいね・リポストのボタンは、結果を画面に反映し終えるまで押せない                       |
| postToolbar-s1  | 「…」メニューの削除は自分の投稿にだけ表示する                                          |
| postToolbar-e6  | 削除は確認ダイアログを経て、再読み込みなしでタイムラインから投稿を消す                 |
| postToolbar-e7  | 返信すると、再読み込みなしで返信先の返信の件数を増やす                                 |
| postToolbar-e8  | 「リンクをコピー」で、投稿のスレッドのURLをコピーする                                  |
| postToolbar-s2  | いいね済みの投稿は、いいねボタンのハートを塗りつぶす                                   |
| postToolbar-e9  | 自分の投稿を「プロフィールにピン留め」で確認なしにピン留めし、「ピン留めを外す」で外す |
| postToolbar-e10 | 別の投稿がピン留め中でも、確認なしにピン留めを入れ替える                               |

ピン留めは、プロフィールの他の項目を保ったままピン留めの投稿だけを書き換える。

削除も投稿と同じく、appviewで見えなくなるまで待ってから画面を更新する。

## 引用投稿

引用している投稿を、本文の下に枠で囲んで表示する。

| ID       | 仕様                                                                   |
| -------- | ---------------------------------------------------------------------- |
| quote-s1 | 引用している投稿の投稿者名と本文を表示する                             |
| quote-s2 | 画像付きの引用投稿は、画像と引用している投稿の両方を表示する           |
| quote-s3 | 引用される投稿の画像を表示する                                         |
| quote-s4 | 引用されている投稿の投稿者のアバターを表示する                         |
| quote-s5 | 引用される投稿のリンクカードを表示する                                 |
| quote-e1 | 引用されている投稿をタップすると、そのスレッドを開く                   |
| quote-s6 | 引用される投稿が削除されていれば、削除されたことを示す枠を表示する     |
| quote-s7 | フィードジェネレーターの引用は、フィード名・作成者・説明を枠で表示する |
| quote-s8 | 引用される投稿の本文も、facetsの範囲をリンクにする                     |
| quote-s9 | スレッドで選んだ投稿のフィードジェネレーターの引用も同じ枠で表示する   |

引用が解除された場合も、公式クライアントと同じく理由を示す枠を表示する。

## リンクカード

投稿のリンクカードを、本文の下に枠で囲んで表示する。

| ID          | 仕様                                                                 |
| ----------- | -------------------------------------------------------------------- |
| linkCard-s1 | サムネイル・タイトル・説明を表示し、選ぶとリンク先を新しいタブで開く |
| linkCard-s2 | x.com・twitter.comのツイートは、リンクカードの代わりに埋め込む       |
| linkCard-s3 | 埋め込んだツイートの中の操作は、投稿の詳細への遷移より優先する       |

ツイートの埋め込みはTwitter公式のスクリプトで表示し、トラッキングを避ける設定を付ける。

## 投稿画像

投稿の画像を、本文の下に並べて表示する。

| ID            | 仕様                                          |
| ------------- | --------------------------------------------- |
| postImages-s1 | 1枚のときは、投稿の幅いっぱいに表示する       |
| postImages-e1 | gallery埋め込みの画像も、すべて並べて表示する |
| postImages-s2 | 5枚以上のときは、横スクロールで表示する       |

## 投稿動画

投稿の動画を、本文の下にプレイヤーで表示する。HLSで再生し、使えないブラウザではネイティブ再生にする。

| ID           | 仕様                                               |
| ------------ | -------------------------------------------------- |
| postVideo-s1 | 停止中は中央に再生ボタンを表示する                 |
| postVideo-s2 | 再生ボタンの横に、経過時間と動画の長さを表示する   |
| postVideo-s3 | サムネイルを表示し、ALTをプレイヤーのラベルにする  |
| postVideo-e1 | 再生ボタンを押すと、playlistを取得して再生を始める |
| postVideo-s4 | 引用された投稿の動画も、引用した投稿の中に表示する |

## 画像の拡大表示

投稿画像や、プロフィールのアイコン・バナーを選ぶと、画面を半透明の黒で覆って画像を大きく表示する。URLは変えないが履歴を1つ積み、ブラウザの「戻る」で閉じられる。

| ID             | 仕様                                                     |
| -------------- | -------------------------------------------------------- |
| imageViewer-s1 | 投稿画像を選ぶと、スレッドを開かずに拡大して表示する     |
| imageViewer-s2 | 複数の画像は、前後に切り替えられる                       |
| imageViewer-s3 | 画像の下にALTを表示する                                  |
| imageViewer-s4 | 閉じるボタンかEscキーで閉じる                            |
| imageViewer-s5 | 複数の画像は、横スワイプで前後に切り替えられる           |
| imageViewer-s6 | ピンチ操作か拡大ボタンでさらにズームできる               |
| imageViewer-s7 | プロフィールのアイコンかバナーを選ぶと、拡大して表示する |
| imageViewer-e1 | ブラウザの戻るで閉じ、元の画面にとどまる                 |
