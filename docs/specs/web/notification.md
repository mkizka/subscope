# Web仕様: 通知

## 通知

通知ページ（`/notifications`）に、追跡アカウントからの通知を表示する。

| ID              | 仕様                                                                |
| --------------- | ------------------------------------------------------------------- |
| notification-e1 | いいね・リポストの通知に、相手の名前と対象の投稿の本文を表示する    |
| notification-e2 | フォローの通知に、相手の名前を表示する                              |
| notification-e3 | リプライ・引用・メンションの通知に、相手の名前とその投稿を表示する  |
| notification-e4 | 通知を新しい順に並べ、下までスクロールすると古い通知を読み込む      |
| notification-e5 | 未読の通知は背景色で区別し、開いた後に再表示すると既読にする        |
| notification-s1 | モバイルでは、下のタブの通知に未読数を表示する                      |
| notification-s2 | 通知に、種類を表す色付きのアイコンと相手のアバターを表示する        |
| notification-s3 | 「通知はまだありません」は、読み込みが終わって0件のときだけ表示する |
| notification-s4 | 読み込み中は、通知の形のスケルトンを6行表示する                     |

## プッシュ通知

この端末でプッシュ通知を受け取るかを、設定ページ（`/settings`）の「通知」のスイッチで切り替える。設定は端末ごとで、アカウントには保存しない。プッシュ通知をタップすると通知ページを開く。吹き出しは外を押すと閉じる。

| ID              | 仕様                                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| pushSetting-e1  | スイッチをオンにすると、通知が届いたときにこの端末へプッシュ通知を送る                                                     |
| pushSetting-e2  | スイッチをオフにすると、この端末へプッシュ通知を送らない                                                                   |
| pushSetting-e3  | ログアウトすると、この端末へプッシュ通知を送らない                                                                         |
| pushSetting-e4  | サーバーから購読を消せなくても、ブラウザの購読は解除する                                                                   |
| pushSetting-e5  | 通知ページの案内の「オンにする」を押すと、プッシュ通知を受け取るようにして、案内を「プッシュ通知をオンにしました」に変える |
| pushSetting-s1  | 受け取らない設定のときは、スイッチをオフにする                                                                             |
| pushSetting-s2  | 受け取る設定のときは、スイッチをオンにする                                                                                 |
| pushSetting-s3  | ブラウザで通知をブロックしているときは、スイッチの代わりに「ブロック中」を表示する                                         |
| pushSetting-s4  | ブラウザがプッシュ通知に対応していないときは、スイッチの代わりに「非対応」を表示する                                       |
| pushSetting-s6  | 通知の許可ダイアログが選ばれずに閉じたときは、スイッチをオフのままにする                                                   |
| pushSetting-s7  | サーバーにVAPID鍵がないときは、「通知」の欄を表示しない                                                                    |
| pushSetting-s8  | 受け取らない設定のときは、通知一覧の上に「オンにする」ボタン付きの案内を表示する                                           |
| pushSetting-s9  | 通知ページの見出しの右端に、設定ページを開く「通知の設定」ボタンを表示する                                                 |
| pushSetting-s10 | 「ブロック中」を押すと、ブラウザのサイト設定で通知を許可するよう吹き出しで案内する                                         |
| pushSetting-s11 | 「非対応」を押すと、iPhone・iPadではホーム画面に追加して開くと使えることを吹き出しで案内する                               |
| pushSetting-s12 | 通知一覧の上の案内は、受け取る設定・ブロック中・非対応・読み込み中・VAPID鍵なしのときは表示しない                          |

サーバーに残った購読は、プッシュサーバーが410を返したときにWorkerが消す。
