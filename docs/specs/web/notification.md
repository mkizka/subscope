# Web仕様: 通知

## 通知

中央カラムの通知ページ（`/notifications`）に表示する。通知になるのは追跡アカウントからのものだけ。

- notification-e1: いいね・リポストの通知には相手の名前と対象の投稿の本文を表示する
- notification-e2: フォローの通知には相手の名前を表示する
- notification-e3: リプライ・引用・メンションの通知には、相手の名前とその投稿を表示する
- notification-e4: 通知を新しい順に並べ、下までスクロールすると古い通知を読み込む
- notification-e5: 未読の通知は背景色で区別し、通知を開いた後に再表示すると既読にする
- notification-s1: モバイルでは、未読があるとき下のタブの通知に未読数を表示する
- notification-s2: 通知には種類を表す色付きのアイコンと相手のアバターを表示する
- notification-s3: 通知の読み込み中は「通知はまだありません」を表示せず、読み込みが終わって0件のときだけ表示する
- notification-s4: 通知の読み込み中は左にアイコン列、右にアバター・文・ハンドル・本文を持つ通知の形のスケルトンを6行表示する

## プッシュ通知

この端末でプッシュ通知を受け取るかの切り替えは、設定ページ(`/settings`)の「通知」にスイッチで表示する。切り替えは端末ごとで、アカウントの設定ではない。プッシュ通知をタップすると `/notifications` を開く。通知ページ(`/notifications`)の見出し「通知」の右端には、設定ページへ移動する歯車のボタンを置く。サーバーにVAPID鍵が設定されていないときは、「通知」のセクションを表示しない。吹き出しは外を押すと閉じる。

- pushSetting-e1: 設定ページのスイッチをオンにすると、通知が追加されたときにその端末へプッシュ通知を送る
- pushSetting-e2: 設定ページのスイッチをオフにすると、その端末へプッシュ通知を送らない
- pushSetting-e3: ログアウトすると、その端末へプッシュ通知を送らない
- pushSetting-e4: サーバーへの購読の削除に失敗しても、その端末のブラウザの購読は解除する。サーバーに残った購読は、プッシュサーバーが410を返したときにWorkerが削除する
- pushSetting-e5: 通知ページの案内の「オンにする」を押すと、その端末へプッシュ通知を送るようにして、案内を「プッシュ通知をオンにしました」に変える
- pushSetting-s1: 受け取らない設定のときは、スイッチをオフにする。説明文は表示しない
- pushSetting-s2: 受け取る設定のときは、スイッチをオンにする。説明文は表示しない
- pushSetting-s3: ブラウザで通知をブロックしているときは、スイッチの代わりに行の右端へ「ブロック中」を表示する。押すと、ラベルの下に「ブラウザのサイト設定で、このサイトの通知を許可すると使えます。」を吹き出しで表示する
- pushSetting-s4: プッシュ通知に対応していないブラウザでは、スイッチの代わりに行の右端へ「非対応」を表示する。押すと、「iPhone・iPadでは、このサイトをホーム画面に追加して開くと使えます。」を吹き出しで表示する
- pushSetting-s5: 切り替えている間は、スイッチを無効にして横にスピナーを表示する
- pushSetting-s6: スイッチをオンにして通知の許可ダイアログが選択されずに閉じたときは、何も表示せずスイッチをオフのままにする
- pushSetting-s7: サーバーにVAPID鍵が設定されていないときは、「通知」のセクションを表示しない
- pushSetting-s8: 受け取らない設定のときだけ、通知一覧の上に「プッシュ通知を受け取る」の案内と「オンにする」ボタンを表示する。受け取る設定・ブロック中・非対応・読み込み中・VAPID鍵なしのときは表示しない
- pushSetting-s9: 通知ページの見出しの右端に、設定ページへ移動する「通知の設定」ボタンを表示する
