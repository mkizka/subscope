# Web仕様: タイムライン

## タイムライン

ログイン後のトップページに「フォロー中」と「ローカル」のタブを出し、最初はフォロー中のタイムラインを表示する。投稿は区切り線で区切り、名前・時刻・本文の下にツールバーを出す。

| ID           | 仕様                                                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| timeline-e1  | 自分とフォロー先の投稿を、新しいものほど上に並べる                                                                             |
| timeline-s1  | いいね数・リポスト数は1以上のときだけ表示する                                                                                  |
| timeline-e2  | 返信先かスレッドの起点が他人の投稿であるリプライは含めず、親投稿に返信の件数を表示する                                         |
| timeline-e3  | 一番下の2画面分手前までスクロールすると、続きの古い投稿を読み込む                                                              |
| timeline-e4  | 投稿の時刻はブラウザの現在時刻からの経過時間で表示する                                                                         |
| timeline-s2  | 本文のfacetsのリンクは、そのURLを新しいタブで開くリンクにする                                                                  |
| timeline-s3  | 本文のfacetsのメンションは、そのアカウントのプロフィール全体ページへのリンクにする                                             |
| timeline-e5  | 返信先とスレッドの起点がどちらも投稿者自身の投稿であるリプライは含める                                                         |
| timeline-e6  | 投稿は1回に50件ずつ読み込む                                                                                                    |
| timeline-s4  | 続きの古い投稿を読み込み終えるまで、一覧の下にスピナーを表示する                                                               |
| timeline-s6  | 一覧に返信先の投稿があれば、間に別の投稿があっても返信先から古い順に続けて並べ、アイコンを線で繋げる                           |
| timeline-s7  | リポストした人の表示は投稿者のアイコンより上の行に出す                                                                         |
| timeline-s8  | 投稿には投稿者の名前の隣にハンドルを表示する                                                                                   |
| timeline-s9  | 「○○がリポスト」をタップすると、○○のプロフィール全体ページを開く                                                               |
| timeline-s10 | 本文のfacetsのハッシュタグは、そのタグを投稿タブで検索する検索ページ（`/search?q=%23タグ`）へのリンクにする                    |
| timeline-e8  | 表示中は60秒ごとに投稿を自動で読み込み直す                                                                                     |
| timeline-s11 | 線で繋げた投稿が4件以上ある場合は、起点・最後の投稿の返信先・最後の投稿の3件だけを表示する                                     |
| timeline-s12 | 線で繋げた投稿を省略したら、起点と返信先の間に省略した件数を点線つきのリンクで表示する                                         |
| timeline-s13 | 省略した件数の表示は、最後の投稿のスレッドページへのリンクにする                                                               |
| timeline-e9  | 選択中のタブか、同じタイムラインを指すメニューのホームをタップすると、先頭へスクロールして読み込み直し、その間「更新中」を出す |
| timeline-e10 | 自動更新の読み込み中は、スピナー付きの「更新中」の表示を、上部のタブのすぐ下に投稿へ重ねて浮かせる                             |
| timeline-e11 | 「更新中」の表示は、スクロールしても上部のタブと一緒に動く                                                                     |

自分の投稿に続けて書いたスレッドは、公式クライアントのフォロー中フィードと同じく表示する。timeline-s6の並べ方は、プロフィール・リスト・検索の投稿一覧でも同じにする。

facetsのない本文は、公式クライアントと同じくURLを含んでいてもリンクにしない。本文の表示は、タイムライン以外の投稿カードとスレッドでも同じにする。

未読箇所からの再開は扱わない。getTimelineのcursorは、指定日時より古い投稿しか返せないため。

## ローカルタイムライン

トップページの「ローカル」タブ（`/?tab=local`）に、このサーバーのメンバーの投稿とリポストを表示する。見せ方と読み込みはフォロー中のタイムラインと同じにする。

| ID               | 仕様                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------ |
| localTimeline-e1 | 「ローカル」タブを選ぶと、このサーバーのメンバーの投稿を新しいものほど上に表示する         |
| localTimeline-e2 | 「ローカル」タブには、メンバーではないアカウントの投稿は、メンバーのフォロー先でも出さない |
| localTimeline-e3 | 「フォロー中」タブを選ぶと、フォロー中のタイムラインに戻る                                 |

## 過去の投稿の同期状態

「フォロー中」タブの下に、自分の過去の投稿を同期し終えたかを1行の帯で知らせる。

| ID                | 仕様                                                                                                                   |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------- |
| backfillBanner-s1 | 自分の同期中は「過去の投稿を同期しています」の帯を出す                                                                 |
| backfillBanner-s2 | 自分の同期がエラーなら、「過去の投稿を同期できていません」の帯を出す                                                   |
| backfillBanner-s3 | 自分の同期が終わっていれば、帯を出さない                                                                               |
| backfillBanner-e1 | 同期中かエラーの間は30秒ごとに状態を確認し、終わったら「過去の投稿の同期が終わりました」の帯と「更新する」ボタンを出す |
| backfillBanner-e2 | 「更新する」を押すと、タイムラインを読み込み直して帯を消す                                                             |

状態は、Workerが保存したバックフィルの状態（[バックフィルの状態の確認](../worker/backfill.md#バックフィルの状態の確認)）を読む。まだ確認していなければ同期中として扱い、読み込むまでは帯を出さない。帯は画面上部に固定しない。

フォロー先の状態は見ない。deactivatedなどで同期できないフォロー先がいても、帯が消えるようにするため。
