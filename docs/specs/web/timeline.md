# Web仕様: タイムライン

## タイムライン

ログイン後のトップページの中央カラムに、「フォロー中」と「ローカル」のタブを付けてタイムラインを表示する。最初は左の「フォロー中」を選び、フォロー中のタイムラインを表示する。リポストは投稿者のアイコンより上の行に「○○がリポスト」と出す。投稿は区切り線で区切って並べ、名前・時刻・本文の下に投稿のツールバーを出す。

- timeline-e1: 自分とフォロー先の投稿を、新しいものほど上に並べる
- timeline-s1: いいね数・リポスト数は1以上のときだけ表示する
- timeline-e2: 返信先かスレッドの起点が他人の投稿であるリプライは含めず、親投稿に返信の件数を表示する
- timeline-e3: 一番下の2画面分手前までスクロールすると、続きの古い投稿を読み込む
- timeline-e4: 投稿の時刻はブラウザの現在時刻からの経過時間で表示する
- timeline-s2: 本文のうちfacetsでリンクが付いた範囲は、そのURLを新しいタブで開くリンクにする
- timeline-s3: 本文のうちfacetsでメンションが付いた範囲は、そのアカウントのプロフィール全体ページへのリンクにする
- timeline-e5: 返信先とスレッドの起点がどちらも投稿者自身の投稿であるリプライは含める
- timeline-e6: 投稿は1回に50件ずつ読み込む
- timeline-s4: 続きの古い投稿を読み込み終えるまで、一覧の下にスピナーを表示する
- timeline-s5: タイムラインを開くと、投稿の読み込みを待たずに画面を表示し、読み込み終えるまで、アイコン・名前・本文・ツールバーを持つ投稿の形のスケルトンを表示する
- timeline-s6: 一覧の中に返信先の投稿があれば、間に別の投稿があっても返信先を上にして古い順に並べ、アイコンの間を線で繋げる
- timeline-s7: リポストした人の表示は投稿者のアイコンより上の行に出す
- timeline-s8: 投稿には投稿者の名前の隣にハンドルを表示する
- timeline-s9: 「○○がリポスト」をタップすると、○○のプロフィール全体ページを開く
- timeline-s10: 本文のうちfacetsでハッシュタグが付いた範囲は、そのハッシュタグを投稿タブで検索する検索ページ（`/search?q=%23タグ`）へのリンクにする
- timeline-e8: 表示中は60秒ごとに投稿を自動で読み込み直し、読み込み中は一覧の上部に、スピナー付きの「更新中」の表示を投稿の上、上部のタブの下に重ねて浮かせ、スクロールしても上部のタブとの位置関係を変えず、タブと一緒に動く
- timeline-s11: 線で繋げた投稿が4件以上ある場合は、起点・最後の投稿の返信先・最後の投稿の3件だけを表示し、起点と返信先の間に省略した投稿の件数を、リンクと分かる見た目で点線つきで表示する。この表示は最後の投稿のスレッドページへのリンクにする
- timeline-e9: 表示中のタイムラインと同じものを指すメニューのホーム、またはフォロー中・ローカルのタブをタップすると、先頭へスクロールして投稿を読み込み直し、読み込み中は timeline-e8 と同じ「更新中」の表示を出す

自分の投稿に続けて書いたスレッドは、公式クライアントのフォロー中フィードと同じく表示する。timeline-s6の並べ替えは、プロフィール・リスト・検索の投稿一覧でも共通に行う。

公式クライアントと同じく、facetsのない本文はURLを含んでいてもリンクにしない。タイムライン以外でも、投稿カードとスレッドの選んだ投稿の本文は同じように表示する。

未読箇所からの再開は扱わない。`app.bsky.feed.getTimeline` のcursorは指定日時より古い投稿しか返せないため。

## ローカルタイムライン

トップページの「ローカル」タブ（`/?tab=local`）に、このサーバーのメンバーの投稿とリポストを新しいものほど上に表示する。投稿の見せ方や読み込みはフォロー中のタイムラインと同じにする。

- localTimeline-e1: 「ローカル」タブを選ぶと、このサーバーのメンバーの投稿を新しいものほど上に表示する
- localTimeline-e2: 「ローカル」タブには、メンバーのフォロー先であってもメンバーではないアカウントの投稿は表示しない
- localTimeline-e3: 「フォロー中」タブを選ぶと、フォロー中のタイムラインに戻る

## 過去の投稿の同期状態

タイムラインの「フォロー中」タブの下に、自分の過去の投稿を同期し終えたかを1行の帯で知らせる。

- backfillBanner-s1: 自分の同期中は「過去の投稿を同期しています」の帯を出す
- backfillBanner-s2: 自分の同期がエラーなら、「過去の投稿を同期できていません」の帯を出す
- backfillBanner-s3: 自分の同期が終わっていれば、帯を出さない
- backfillBanner-e1: 同期中かエラーの間は30秒ごとに状態を確認し直し、同期が終わったら「過去の投稿の同期が終わりました」の帯と「更新する」ボタンを出す
- backfillBanner-e2: 「更新する」を押すと、タイムラインを読み込み直して帯を消す

状態はWorkerがアカウントに保存したバックフィルの状態(worker.md の「バックフィルの状態の確認」)を読み、まだ確認していなければ同期中として扱う。フォロー先の状態は見ない。deactivatedなどで同期できないフォロー先がいても帯が消えなくならないようにするため。状態を読み込むまでは帯を出さない。帯は見出しと違って画面上部に固定しない。
