# Web仕様: サーバー

## サーバー

中央カラムの `/server` に、このサーバーの情報とアカウントの一覧をPCでもモバイルでも同じ内容で表示する。PCの左カラムのメニュー、右カラムのカード、モバイルのドロワーから開く。ページ内にサーバー名とアイコンは出さない。アカウントは「メンバー」「誰かがフォロー」のタブで切り替え、「誰かがフォロー」は `?tab=tracked`。「誰かがフォロー」はフォローされているアカウントのこと。

- server-s1: 見出し「サーバーについて」の下に、Subscopeの概要と、見出し「仕組み」「Subscopeが目指すもの」の説明を表示する
- server-e1: 項目「運営者」に、最初に管理者になった1人のアイコンと名前を表示し、選ぶとそのアカウントのプロフィール全体ページに移動する
- server-e2: 項目「サーバーDID」に、サーバーDID `did:web:{ホスト}#bsky_appview` を表示する
- server-e3: サーバーDIDの文字列とコピーアイコンをひとつのボタンにし、押すとサーバーDIDをクリップボードにコピーできる
- server-s2: 「メンバー」「誰かがフォロー」のタブを表示し、タブ見出しに各タブの人数を出す
- server-s3: 「メンバー」タブではメンバーの一覧（名前、ハンドル、自己紹介）を表示する
- server-e4: 「誰かがフォロー」タブでは、フォローされているアカウント（名前、ハンドル）を、フォローしているメンバーが多い順に一覧表示する
- server-e5: 一覧のアカウントを選ぶと、そのアカウントのプロフィール全体ページに移動する
- server-s4: 管理者には「運営者」ラベルを表示する
- server-s6: 「誰かがフォロー」タブには、フォローしているメンバーの数を「n人からフォロー」と表示する
- server-e6: 旧URLの `/server/accounts`、`/accounts`、`/registered-accounts`、`/tracked-accounts` は、`/server` の該当タブへ移動する
- server-e7: タブの下の検索欄に入力すると、選んでいるタブの全件から表示名・ハンドルの部分一致で絞り込み、検索語を `?q=` に入れる
- server-s8: 検索に一致するアカウントがないときは「アカウントが見つかりません」を表示する
- server-s9: 運営者とサーバーDIDは、読み込み終えるまで値の場所にスケルトンを表示する

メンバーの人数は最初に読み込む100件までを数え、それより多いときは「100+」と表示する。
