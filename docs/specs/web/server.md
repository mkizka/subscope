# Web仕様: サーバー

## サーバー

`/server` に、「サーバー情報」としてこのサーバーの運営者・サーバーDIDとアカウントの一覧を出す。PCでもモバイルでも同じ内容にする。アカウントは「メンバー」と「誰かがフォロー」（メンバーにフォローされているアカウント）のタブで切り替え、後者は `/server?tab=tracked` で開ける。

| ID         | 仕様                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------- |
| server-e1  | 「運営者」に最初の管理者を表示し、選ぶとそのプロフィールに移動する                                                     |
| server-e2  | 「サーバーDID」に、did:web:ホスト名#bsky_appview の形のサーバーDIDを表示する                                           |
| server-e3  | サーバーDIDを押すと、クリップボードにコピーする                                                                        |
| server-s3  | 「メンバー」タブでは、メンバーを自己紹介つきで一覧表示する                                                             |
| server-e4  | 「誰かがフォロー」タブでは、フォローしているメンバーが多い順にアカウントを一覧表示する                                 |
| server-e5  | 一覧のアカウントを選ぶと、そのアカウントのプロフィールに移動する                                                       |
| server-s4  | 管理者には「運営者」ラベルを表示する                                                                                   |
| server-s6  | 「誰かがフォロー」タブでは、フォローしているメンバーの数を「n人からフォロー」と表示する                                |
| server-e6  | 旧URLの `/server/accounts`、`/accounts`、`/registered-accounts`、`/tracked-accounts` は `/server` の該当タブに移動する |
| server-e7  | 検索欄に入力すると、選んでいるタブの全件を表示名かハンドルの部分一致で絞り込み、検索語をURLに入れる                    |
| server-s8  | 絞り込みに一致するアカウントがないときは「アカウントが見つかりません」と表示する                                       |
| server-s9  | 運営者とサーバーDIDは、読み込み中にスケルトンを表示する                                                                |
| server-s12 | 見出しに「サーバー情報」を表示する                                                                                     |
| server-s11 | 「Subscopeとは」を押すと、Subscopeの説明をダイアログで開く                                                             |
