# Web仕様: プロフィール・リスト

## プロフィール

中央カラムの `/ハンドル` に、アカウントのプロフィールと投稿を表示する。ハンドルが無効なアカウントは、ハンドルの代わりにDIDを使う。タブはURLを変えずに画面内で切り替え、開いたときは「投稿」タブを表示する。

| ID          | 仕様                                                                                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| profile-e1  | 左カラムの「プロフィール」から、自分のプロフィール（バナー、アイコン、名前、ハンドル、自己紹介、フォロー数、フォロワー数、投稿一覧）を表示する               |
| profile-e2  | フォローボタンでフォローし、もう一度押すと外す                                                                                                               |
| profile-s1  | 自分のプロフィールにはフォローボタンを出さない                                                                                                               |
| profile-s2  | フォローボタンは、押した結果が画面に反映されるまで押せない                                                                                                   |
| profile-e3  | 「投稿」タブは他人へのリプライを除いた投稿を、「リプライ」タブはリプライを含めた投稿を表示する                                                               |
| profile-e8  | 「投稿」タブは自分の投稿への自分のリプライを含め、タイムラインと同じく線で繋げる                                                                             |
| profile-e12 | 「投稿」タブの1ページ目は、ピン留めした投稿を「ピン留め」の表示付きで先頭に出し、元の位置には出さない                                                        |
| profile-e9  | 「リプライ」タブは、返信先の投稿が一覧にないとき、リプライの上に返信先を表示して線で繋げる                                                                   |
| profile-e4  | 「いいね」タブは、どのアカウントでも、そのアカウントがいいねした投稿を表示する                                                                               |
| profile-e5  | 「メディア」タブは画像付きの投稿だけを表示する                                                                                                               |
| profile-e11 | 「動画」タブは動画付きの投稿だけを表示する                                                                                                                   |
| profile-e10 | 各タブは、一番下の2画面分手前までスクロールすると続きを読み込む                                                                                              |
| profile-e6  | タイムラインとスレッドで投稿者のアイコンか名前を選ぶと、そのプロフィールに移動する                                                                           |
| profile-s4  | 開くとすぐ画面を出し、読み込み終えるまでバナー・アイコン・名前・自己紹介・投稿の場所をスケルトンにする                                                       |
| profile-s5  | タブを切り替えると、ヘッダーとタブはそのままで、投稿の場所だけを読み込み終えるまでスケルトンにする                                                           |
| profile-s6  | 「リスト」タブから他のタブに切り替えたときも、投稿の場所だけをスケルトンにする                                                                               |
| profile-s7  | 自己紹介の下にプロフィールのリンクを丸いボタンで並べ、選ぶと新しいタブで開く                                                                                 |
| profile-s8  | アイコンが未設定のアカウントには、人型のシルエットを出す（アイコンを出すすべての場所で共通）                                                                 |
| profile-s9  | 自分をフォローしているアカウントには、ハンドルの横に「フォローされています」を出す                                                                           |
| profile-s10 | 追跡アカウントでないときは、ハンドルの横に「同期対象外」を出す                                                                                               |
| profile-s11 | メンバーでないときは、全てのタブの下に、表示が不十分な場合があることを出す                                                                                   |
| profile-s16 | メンバーのプロフィールには、表示が不十分であることの案内を出さない                                                                                           |
| profile-s12 | 知り合い（自分のフォローのうち、そのアカウントをフォローしている人）がいるときは、フォロー数の下にアイコンと「Bob、Carolほか12人がフォローしています」を出す |
| profile-s13 | 知り合いがいないときと自分のプロフィールでは、知り合いの行を出さない                                                                                         |
| profile-s14 | 知り合いの行を選ぶと、フォロワー一覧の「知り合い」タブに移動する                                                                                             |

メンバー以外のアカウントは保存する範囲が狭く、プロフィールの投稿や投稿数が実際より少なくなる。メンバー以外の追跡アカウントは、過去の投稿を追跡開始の1日前以降の分しか保存しない。追跡アカウントでないアカウントは、引用やリポストの元として取得した投稿とプロフィールだけを保存する。

いいねは追跡アカウントのものだけを保存するため、それ以外のアカウントの「いいね」タブは空になる。

## フォロー・フォロワー

中央カラムの `/ハンドル/follows` と `/ハンドル/followers` に、アカウントのフォローとフォロワーを一覧表示する。

| ID            | 仕様                                                                                                                        |
| ------------- | --------------------------------------------------------------------------------------------------------------------------- |
| followList-e1 | プロフィールのフォロー数から、フォローの一覧（名前、ハンドル、自己紹介）を開く                                              |
| followList-e2 | プロフィールのフォロワー数から、フォロワーの一覧（名前、ハンドル、自己紹介）を開く                                          |
| followList-e3 | 一覧のアカウントを選ぶと、そのプロフィールに移動する                                                                        |
| followList-e7 | 見出しは「{名前}のフォロー」「{名前}のフォロワー」とし、戻るボタンでプロフィールに移動する                                  |
| followList-s3 | フォロワー一覧に「すべて」「知り合い」「メンバー」のタブを出す                                                              |
| followList-e5 | 「メンバー」タブ（`?filter=registered`）は、フォロワーのうちメンバーだけを表示する                                          |
| followList-e8 | 「知り合い」タブ（`?filter=known`）は、フォロワーのうち自分がフォローしている人だけを、自分がフォローした新しい順に表示する |
| followList-e6 | サーバーページの「誰かがフォロー」タブで「n人からフォロー」を押すと、フォロワー一覧の「メンバー」タブに移動する             |
| followList-s4 | フォローが0件のときは「フォローしているアカウントはありません」を出す                                                       |
| followList-s5 | フォロワーが0件のときは「フォロワーはいません」を出す                                                                       |
| followList-s6 | 「知り合い」タブが0件のときは「知り合いのフォロワーはいません」を出す                                                       |

ハンドルが無効なアカウントはハンドルの行を出さず、名前が無ければDIDを名前の行に出す。一覧は最初の100件だけを表示する。「知り合い」タブだけは50件ずつ読み込み、スクロールで続きを読み込む。

## リスト

アカウントが作ったリストを、プロフィールの「リスト」タブの一覧と、中央カラムの詳細（`/ハンドル/lists/rkey`）で表示する。詳細のURLはbsky.appに合わせる。詳細の「投稿」「メンバー」タブはURLを変えずに切り替える。

| ID       | 仕様                                                                                                                                   |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| list-e1  | プロフィールの「リスト」タブに、そのアカウントが作ったリスト（名前、説明）を一覧表示する                                               |
| list-e10 | リスト一覧はプロフィールのヘッダーとタブの下に、そのアカウントのリストだけを出す。自分のプロフィールでも作成フォームは出さない         |
| list-s7  | 一覧の各行の左にリストの画像を出し、未設定ならリストのアイコンを出す                                                                   |
| list-e2  | リストを選ぶと、ヘッダー（戻るボタン、作成者）、名前と説明、メンバーの投稿を新しい順に表示する                                         |
| list-e9  | メンバーの投稿は、タイムラインと同じ規則でリプライを絞り込む                                                                           |
| list-e3  | 詳細の「メンバー」タブに、リストのメンバーを一覧表示する                                                                               |
| list-e11 | サイドメニューの「リスト」から、自分のリストの管理画面（`/lists`）を開き、自分のリストを一覧表示する                                   |
| list-e4  | 管理画面の「新しいリスト」から、名前と説明を入力してリストを作る                                                                       |
| list-e5  | 自分のリスト詳細の「…」メニューから、名前と説明を編集する                                                                              |
| list-e6  | 自分のリスト詳細の「…」メニューから、確認のうえリストとメンバーを削除し、プロフィールに戻る                                            |
| list-e7  | 自分のリストの「メンバー」タブで、ハンドルを入力してアカウントを追加する                                                               |
| list-e8  | 自分のリストの「メンバー」タブで、メンバーを削除する                                                                                   |
| list-e12 | プロフィールのフォローボタンの右の「…」メニューの「リストに追加」から、そのアカウントを自分のリストに追加・削除する                    |
| list-e13 | 自分のプロフィールにも「…」メニューを出す                                                                                              |
| list-s8  | 「リストに追加」ダイアログは自分のキュレーションリストを新しい順に並べ、入っているリストに「削除」、入っていないリストに「追加」を出す |
| list-s10 | 「リストに追加」ダイアログは読み込み中にスケルトンを出し、リストが無いときは「リストがありません。」と管理画面へのリンクを出す         |

モデレーションリストはブロック・ミュートを扱わないため表示せず、作れるリストもキュレーションリストだけにする。一覧・投稿・メンバーは最初に読み込む分だけを表示する。
