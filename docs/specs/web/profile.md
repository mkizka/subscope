# Web仕様: プロフィール・リスト

## プロフィール

中央カラムの全体ページ（`/ハンドル`）で表示する。ハンドルが無効（`handle.invalid`）なときはハンドルの代わりにDIDを使う。

- profile-e1: 左カラムの「プロフィール」から、中央カラムに自分のプロフィール（バナー、アイコン、名前、ハンドル、自己紹介、フォロー数、フォロワー数、投稿一覧）を表示する
- profile-e2: 全体ページのフォローボタンでそのアカウントをフォローし、もう一度押すと外す
- profile-s1: 自分のプロフィールにはフォローボタンを出さない
- profile-e3: 全体ページの「投稿」タブでは他人へのリプライを除いた投稿を、「リプライ」タブではリプライを含めた投稿を表示する
- profile-e4: 全てのアカウントのプロフィールの「いいね」タブに、そのアカウントがいいねした投稿を表示する
- profile-e5: 全体ページの「メディア」タブには画像付きの投稿だけを表示する
- profile-e11: 全体ページの「動画」タブには動画付きの投稿だけを表示する
- profile-s2: フォローボタンは押した結果を画面に反映し終えるまで押せない
- profile-e6: タイムラインとスレッドの投稿のアイコンか名前を選ぶと、投稿者のプロフィール全体ページに移動する
- profile-s3: 追跡アカウントの全体ページにはそのアカウントの過去の投稿の同期状態（同期中・同期済み・同期エラー）をハンドルの横に表示する
- profile-s4: プロフィールを開くと、読み込みを待たずに画面を表示し、読み込み終えるまでバナー・アイコン・名前・自己紹介2行と投稿の場所のスケルトンを表示する。ハンドル・タブ・フォロー数は読み込み後に表示する
- profile-e7: 一度表示したプロフィールに戻ると、読み込み直しを待たずに前回の内容を表示する
- profile-e8: 全体ページの「投稿」タブでは自分の投稿への自分のリプライ(スレッド)を含め、timeline-s6と同じく線で繋げる
- profile-e12: 全体ページの「投稿」タブの1ページ目では、プロフィールでピン留めした投稿を先頭に表示し、投稿の上にリポストと同じ位置で「ピン留め」を出す。元の位置には重ねて表示しない
- profile-e9: 「リプライ」タブでは、返信先の投稿が一覧にない場合、リプライの上に返信先を表示して線で繋げる
- profile-s5: タブを切り替えると、ヘッダーとタブはそのままにして、投稿の場所だけ読み込み終えるまでスケルトンを表示する
- profile-s6: 「リスト」タブから他のタブに切り替えても、ヘッダーとタブはそのままにして、投稿の場所だけ読み込み終えるまでスケルトンを表示する
- profile-s7: プロフィールの自己紹介の下に、プロフィールに設定されたリンクを、枠付きの丸いボタンとして折り返しながら並べて表示する。表示名（なければドメイン）を選ぶと、リンク先を新しいタブで開く
- profile-s8: アイコン画像を設定していないアカウントには、人型のシルエットをアイコンの代わりに表示する（タイムライン、スレッド、通知、一覧、投稿欄など、アイコンを表示するすべての場所で共通）
- profile-s9: 自分をフォローしているアカウントのプロフィール全体ページには、ハンドルの横に「フォローされています」を表示する
- profile-e10: 全体ページの各タブ（投稿・リプライ・メディア・いいね）は、一番下の2画面分手前までスクロールすると、続きの古い投稿を読み込む
- profile-s10: 追跡アカウントでない全体ページには、ハンドルの横に「同期対象外」を表示する
- profile-s11: 追跡アカウントでない全体ページには、タブの下に「このアカウントのデータはサーバーに同期されていません。フォローすると同期を開始します。」を全てのタブで表示する
- profile-s12: 自分がフォローしているアカウントのうちそのアカウントをフォローしている人（知り合い）がいる全体ページには、フォロー数の下に知り合いのアイコン（最大3人）と名前（最大2人）、残りの人数を「Bob、Carolほか12人がフォローしています」の形で表示し、選ぶとフォロワー一覧の「知り合い」タブに移動する
- profile-s13: 知り合いがいない全体ページと自分の全体ページには、知り合いの行を表示しない

いいねは保存対象のアカウント（追跡アカウント）のものだけを保存しているため、それ以外のアカウントのいいねタブは空になる。

同期状態はWorkerがアカウントに保存したもの（worker.md の「バックフィルの状態の確認」）を読み、まだ確認していない人は同期中とする。追跡アカウントでなければ同期状態は表示しない。

## フォロー・フォロワー

中央カラムの `/ハンドル/follows` と `/ハンドル/followers` に、そのアカウントのフォローとフォロワーを一覧表示する。

- followList-e1: プロフィール全体ページのフォロー数から、中央カラムにそのアカウントのフォロー（名前、ハンドル、自己紹介）を一覧表示する
- followList-e2: プロフィール全体ページのフォロワー数から、中央カラムにそのアカウントのフォロワー（名前、ハンドル、自己紹介）を一覧表示する
- followList-e3: 一覧のアカウントを選ぶと、そのアカウントのプロフィール全体ページに移動する
- followList-s1: 一覧の追跡アカウントには過去の投稿の同期状態を表示する
- followList-s2: 一覧を開くと、読み込みを待たずに見出しを表示し、読み込み終えるまでスケルトンを表示する
- followList-e4: 一度表示した一覧に戻ると、読み込み直しを待たずに前回の一覧を表示する
- followList-s3: フォロワー一覧に「すべて」「知り合い」「メンバー」のタブを表示し、「メンバー」には人数を添える
- followList-e5: 「メンバー」タブ（`?filter=registered`）には、そのアカウントをフォローしているメンバーだけを一覧表示する
- followList-e6: サーバーページの「誰かがフォロー」タブの「n人からフォロー」を押すと、そのアカウントのフォロワー一覧の「メンバー」タブに移動する
- followList-e7: 見出しを「{名前}のフォロー」「{名前}のフォロワー」とし、戻るボタンでそのアカウントのプロフィール全体ページに移動する
- followList-s4: 読み込みが終わって0件のときは、フォロー一覧には「フォローしているアカウントはありません」を表示する
- followList-s5: 読み込みが終わって0件のときは、フォロワー一覧には「フォロワーはいません」を表示する
- followList-e8: 「知り合い」タブ（`?filter=known`）には、自分がフォローしているアカウントのうちそのアカウントをフォローしている人だけを、自分がフォローした新しい順に一覧表示する
- followList-s6: 「知り合い」タブの読み込みが終わって0件のときは、「知り合いのフォロワーはいません」を表示する

ハンドルが無効なアカウントは、名前が無ければDIDを名前行に表示し、ハンドル行は表示しない。

一覧は最初に読み込む100件までを表示する。ただし「知り合い」タブは50件ずつ読み込み、一番下の2画面分手前までスクロールすると続きを読み込む。

## リスト

アカウントが作成したリストを、中央カラムの一覧（`/ハンドル/lists`）と詳細（`/ハンドル/lists/rkey`）で閲覧する。URLはbsky.appに合わせる。

- list-e1: プロフィール全体ページの「リスト」から、そのアカウントが作成したリスト（名前、説明）を一覧表示する
- list-e2: 一覧のリストを選ぶと、戻るボタンと作成者を含むヘッダー、リストの名前と説明、リストのメンバーの投稿を新しい順に表示する
- list-e3: リスト詳細の「メンバー」タブで、リストに追加されたアカウントを一覧表示する
- list-e4: 「リスト」の管理画面（`/lists`）で、「新しいリスト」ボタンのダイアログに名前と説明を入力してリストを作成する
- list-e5: 自分のリスト詳細のヘッダーにある「…」メニューから編集ダイアログを開き、リストの名前と説明を編集する
- list-e6: 自分のリスト詳細のヘッダーにある「…」メニューから、確認のうえリストとリストのメンバーを削除し、リスト一覧に戻る
- list-e7: 自分のリストの「メンバー」タブで、ハンドルを入力したアカウントをリストに追加する
- list-e8: 自分のリストの「メンバー」タブで、リストのメンバーをリストから削除する
- list-s4: 「メンバー」タブの追跡アカウントには、過去の投稿の同期状態を表示する
- list-e9: リストのメンバーの投稿はタイムラインと同じ規則でリプライを絞り込む
- list-s5: リスト一覧を開くと、リストの読み込みを待たずに画面を表示し、読み込み終えるまでスケルトンを表示する
- list-s6: リスト詳細を開くと、リストの読み込みを待たずに画面を表示し、読み込み終えるまでスケルトンを表示する
- list-e10: リスト一覧はプロフィールのヘッダーとタブの下に、表示中のアカウントが作成したリストだけを表示し、自分のプロフィールでも作成フォームは表示しない
- list-s7: リスト一覧の各行の左に、リストのアバター画像を表示し、未設定ならリストのアイコンを表示する
- list-e11: サイドメニューの「リスト」から、自分のリストの管理画面（`/lists`）を開き、自分のリストを一覧表示する
- list-e12: プロフィール全体ページのフォローボタンの右にある「…」メニューの「リストに追加」から、自分のリストにそのアカウントを追加・削除する（自分のプロフィールにも出す）
- list-s8: 「リストに追加」ダイアログは、自分のキュレーションリストを新しい順に並べ、そのアカウントが入っているリストに「削除」、入っていないリストに「追加」を出す
- list-s10: 「リストに追加」ダイアログは、開いてから読み込み終えるまでスケルトンを表示し、自分のリストが無いときは「リストがありません。」とリスト管理画面（`/lists`）へのリンクを表示する

モデレーションリストはブロック・ミュートを扱わないため表示せず、作成するリストもキュレーションリストに限る。一覧・投稿・リストのメンバーは最初に読み込む分だけを表示する。
