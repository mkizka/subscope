# Web仕様: スレッド

## スレッド

投稿を選ぶと、中央の画面に `/ハンドル/post/rkey` でその投稿のスレッドを開く。URLは公式クライアントと同じにする。見出しは「スレッド」で、親投稿と返信への返信は縦線で前後の投稿とつなぐ。タイムラインに出ないリプライにも返信できるよう、スレッドの投稿にも投稿のツールバーを出す。

- thread-e1: タイムラインや検索結果の投稿を選ぶと、その投稿のスレッドを開く
- thread-e2: 親投稿はこのサーバーにあるところまでさかのぼって上に、直下の返信は下に並べる
- thread-e3: `/ハンドル/post/rkey` を開くと、その投稿のスレッドを表示する
- thread-e4: 見出しの戻るボタンを押すと、スレッドを開く前の画面に戻る
- thread-s1: 選んだ投稿は本文を大きくし、投稿日時と返信・リポスト・引用・いいねの件数を表示する
- thread-e5: 直下の返信の下には返信への返信を1件ずつたどって並べる
- thread-e6: 選んだ投稿の投稿日時はブラウザのタイムゾーンで表示する
- thread-s2: スレッドの投稿にも投稿のツールバーを表示する
- thread-e7: スレッドで返信ボタンを押すと投稿欄が開き、投稿すると再読み込みなしでスレッドに返信を表示する
- thread-e8: スレッドから戻ると、スレッドを開く前のスクロール位置に戻る
- thread-e9: 選んだ投稿の直下に自分のアイコン付きの「返信を書く」欄を置き、押すとその投稿への返信の投稿欄を開く
- thread-e10: 選んだ投稿を削除すると、ホームに戻る
- thread-e11: スレッドの親投稿や返信を選ぶと、その投稿のスレッドを開く
- thread-e13: 存在しない投稿のスレッドを開くと、再試行せずに「投稿が見つかりません」を表示する
- thread-e14: スクロールしても見出しは画面上部に残り、投稿やツイートの埋め込みより手前に表示する

返信への返信が複数あるときに最初の1件だけをたどるのは、公式クライアントの通常表示(リニア表示)に合わせるため。

時刻はサーバーとブラウザで現在時刻やタイムゾーンが異なり、サーバーで描画するとhydrationの結果が食い違うため、ブラウザでだけ描画する。

## 引用一覧

選んだ投稿の「N件の引用」から、中央の画面に `/ハンドル/post/rkey/quotes` でその投稿を引用した投稿を新しい順に一覧表示する。URLは公式クライアントと同じにする。見出しは「引用」で、戻るボタンでスレッドに戻る。末尾までスクロールすると続きを読み込む。

- quotes-e1: スレッドの選んだ投稿に引用があるときは件数の「N件の引用」を表示し、押すと引用一覧を開く
- quotes-e2: 引用した投稿を新しい順に並べる
- quotes-s2: 引用がないときは「まだ引用されていません」を表示する

## リポスト・いいね一覧

選んだ投稿の「N件のリポスト」「N件のいいね」から、中央の画面に `/ハンドル/post/rkey/reposted-by`、`/ハンドル/post/rkey/liked-by` でリポスト・いいねしたアカウントを一覧表示する。URLは公式クライアントと同じにする。見出しは「リポスト」「いいね」で、戻るボタンでスレッドに戻る。行はフォロー一覧と同じ表示にし、末尾までスクロールすると続きを読み込む。

- reactors-e1: スレッドの選んだ投稿にリポストがあるときは「N件のリポスト」を押すと、リポストしたアカウントの一覧を開く
- reactors-e2: スレッドの選んだ投稿にいいねがあるときは「N件のいいね」を押すと、いいねしたアカウントの一覧を開く
- reactors-s2: だれもいないときは「まだリポストされていません」「まだいいねされていません」を表示する
