# Web仕様: ログイン・設定

## ログイン

atprotoアカウントでOAuthログインし、メンバーでなければ招待コードで登録する。ログイン前に見せる画面はこのログイン画面（`/login`）だけにする。

ログイン画面は、PCでは左にSubscopeの説明、右にログインのフォームを並べ、モバイルでは説明を上に置く。説明の詳しい内容は「Subscopeとは」のモーダルで読める。ログイン前に見せるため、モーダルにはメンバーの一覧や人数を出さない。モーダルは長めの説明を読む前提で、見出しと閉じるボタンを上に固定し、中身だけをスクロールする。高さは画面の85%までにする。

| ID        | 仕様                                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| login-e1  | 最初にログインしたアカウントを管理者として登録する                                                                                   |
| login-e2  | ログインしていないときにトップページを開くと、ログイン画面に移動する                                                                 |
| login-s1  | 管理者がまだいないサーバーでは、最初にログインしたアカウントが管理者になることをログイン画面に出す                                   |
| login-e3  | メンバーでないアカウントでログインすると、ログイン画面で招待コードの入力を求める                                                     |
| login-e4  | 無効な招待コードを入力すると「招待コードが無効または期限切れです」と出す                                                             |
| login-e5  | 有効な招待コードを入力すると、メンバーとして登録してタイムラインに移動する                                                           |
| login-s2  | ログイン画面には、テスト中であることと招待コードで新規登録できることを出す                                                           |
| login-s3  | 招待コードの入力を求めるときは「ログイン」「招待コード」の2段階の手順を出し、今が「招待コード」の段階であることを示す                |
| login-s5  | 管理者がいるサーバーのログイン画面には、登録していないアカウントはログイン後に招待コードの入力が必要なことを出す                     |
| login-s7  | 管理者がいるサーバーのログイン画面には「ログイン」「新規登録」のタブを出し、最初は「ログイン」を選ぶ                                 |
| login-s8  | 「新規登録」タブを押すと、ハンドルと招待コードの入力欄を出す                                                                         |
| login-s9  | 管理者がまだいないサーバーのログイン画面には、タブを出さない                                                                         |
| login-s10 | ログインタブには@passportのアイコン付きの「@passportでログイン」ボタンを出す                                                         |
| login-e6  | 「新規登録」タブで有効な招待コードを入力してログインすると、メンバーとして登録してタイムラインに移動する                             |
| login-e7  | 「新規登録」タブで無効な招待コードを入力してログインすると、招待コードの入力画面に戻って「招待コードが無効または期限切れです」と出す |
| login-e8  | ログイン後にOAuthで要求する権限が変わった場合、ログイン画面に移動する                                                                |
| login-e9  | @passportから戻ってきたハンドルでOAuthログインを始める                                                                               |
| login-e10 | @passportからの戻りが自分の始めたものでなければ、ログイン画面に戻す                                                                  |
| login-s11 | 説明の下の「Subscopeについて」を押すと、「Subscopeとは」のモーダルを開く                                                             |
| login-e11 | 「ログイン」「新規登録」のタブを切り替えても、URLは変えない                                                                          |

OAuthで要求する権限は、webが実際に使うものだけに絞る。対象は、投稿・スレッドゲート・いいね・リポスト・フォロー・リスト・リストアイテムのレコード、ピン留めのためのプロフィールの更新、画像のアップロード、AppViewへのXRPC呼び出しである。XRPC呼び出しはワイルドカードでなくpermission setで許可する。個別の権限指定に対応していないPDSはサポートしない。

ログイン時に要求した権限はセッションに保存し、今の要求と違えば未ログインとして扱う。

@passportでログインするときは、`/login/atpassport` から@passportに移動し、`/login/atpassport/callback` に戻ってきたハンドルでOAuthログインを始める。戻りが自分の始めたものかは、5分だけ有効な署名付きCookieで確かめる。招待コードは@passportに渡さず、ログイン後に入力してもらう。

「新規登録」タブの招待コードはOAuthのstateに載せ、認証後に登録する。メンバーの有無が分かってしまうため、ハンドルだけでメンバーかどうかを調べる処理は置かない。

## 設定

中央カラムの `/settings` に、上から自分のアイコンと名前、アカウント設定へのリンク、この端末のプッシュ通知の切り替え（「プッシュ通知」の仕様を参照）、ログアウトを並べる。PCの左カラムのメニューとモバイルのドロワーから開く。

| ID          | 仕様                                                                                            |
| ----------- | ----------------------------------------------------------------------------------------------- |
| settings-e1 | ログインしていない場合、ログイン画面に移動する                                                  |
| settings-s1 | 自分のアイコン、表示名、ハンドルを表示する                                                      |
| settings-e2 | 「アカウント設定」はログインに使った認可サーバーの `/account` を新しいタブで開くリンクにする    |
| settings-s2 | 「アカウント設定」の下に、認可サーバーのホスト名を使って「{ホスト名} で設定できます」と表示する |
| settings-e3 | 確認ダイアログで「ログアウト」を押すと、ログイン画面に移動する                                  |
| settings-s3 | 「ログアウト」を押すと、ログアウトしてよいかを確認するダイアログを開く                          |
