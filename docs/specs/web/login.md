# Web仕様: ログイン・設定

## ログイン

atprotoアカウントでOAuthログインし、メンバーでなければ招待コードで登録する。ログイン前に見せる画面はこのログイン画面（`/login`）だけにする。

OAuthで要求する権限は、`transition:generic`を使わず、webが実際に使う投稿・スレッドゲート・いいね・リポスト・フォロー・リスト・リストアイテムのレコードと、ピン留めのためのプロフィールレコードの更新、画像のアップロード、AppViewへのXRPC呼び出しだけに絞る。XRPC呼び出しはワイルドカードを使わず、permission set(`me.subsco.authFull`と`app.bsky.authViewAll`)で許可する。個別の権限指定に対応していないPDSはサポートしない。

- login-e1: 最初にログインしたアカウントを管理者として登録する
- login-e2: ログインしていないときにトップページを開くと、ログイン画面に移動する
- login-s1: 管理者がまだいないサーバーでは、最初にログインしたアカウントが管理者になることをログイン画面に出す
- login-e3: メンバーでないアカウントでログインすると、ログイン画面で招待コードの入力を求める
- login-e4: 無効な招待コードを入力すると「招待コードが無効または期限切れです」と出す
- login-e5: 有効な招待コードを入力すると、メンバーとして登録してタイムラインに移動する
- login-s2: ログイン画面にはBlueskyのアカウントでログインする招待制のサーバーであることを出す
- login-s3: 招待コードの入力を求めるときは「ログイン」「招待コード」の2段階の手順を出し、今が「招待コード」の段階であることを示す
- login-s4: 「ログイン」を押してから認証画面に移動するまで、ログインボタンを無効にしてスピナーを出す
- login-s5: 管理者がいるサーバーのログイン画面には、登録していないアカウントはログイン後に招待コードの入力が必要なことを出す
- login-s6: 「登録する」を押してから結果が出るまで、登録ボタンを無効にしてスピナーを出す
- login-s7: 管理者がいるサーバーのログイン画面には「ログイン」「新規登録」のタブを出し、最初は「ログイン」を選ぶ
- login-s8: 「新規登録」タブにはハンドルと招待コードの入力欄を出す
- login-s9: 管理者がまだいないサーバーのログイン画面には、タブを出さない
- login-s10: ログインタブには「@passportでログイン」ボタンを出す
- login-e6: 「新規登録」タブで有効な招待コードを入力してログインすると、メンバーとして登録してタイムラインに移動する
- login-e7: 「新規登録」タブで無効な招待コードを入力してログインすると、招待コードの入力画面に戻って「招待コードが無効または期限切れです」と出す
- login-e8: ログイン後にOAuthで要求する権限が変わった場合、ログイン画面に移動する
- login-e9: @passportから戻ってきたハンドルでOAuthログインを始める
- login-e10: @passportからの戻りが自分の始めたものでなければ、ログイン画面に戻す

@passportでログインするときは、`/login/atpassport` から@passportに移動し、`/login/atpassport/callback` に戻ってきたハンドルでOAuthログインを始める。戻りの照合に使う `atpstate` は、署名付き・httpOnly・5分のCookieに入れる。招待コードは@passportに渡さず、ログイン後の入力画面で求める。

ログイン時に要求した権限はセッションのCookieに保存し、現在の要求と違えば未ログインとして扱う。

「新規登録」タブの招待コードはOAuthのstateに載せ、認証後のコールバックで登録する。ハンドルだけでメンバーかどうかを調べる処理は、メンバーの有無が分かってしまうため置かない。

## 設定

中央カラムの `/settings` に、上から自分のアイコンと名前、アカウント設定へのリンク、この端末のプッシュ通知の切り替え(「プッシュ通知」の仕様を参照)、ログアウトの順に表示する。PCの左カラムのメニューとモバイルのドロワーから開く。

- settings-e1: ログインしていない場合、ログイン画面に移動する
- settings-s1: 自分のアイコン、表示名、ハンドルを表示する
- settings-e2: 「アカウント設定」はログインに使った認可サーバーの `/account` を新しいタブで開くリンクにする
- settings-s2: 「アカウント設定」の下に、認可サーバーのホスト名を使って「{ホスト名} で設定できます」と表示する
- settings-e3: 「ログアウト」を押すと、ログイン画面に移動する
