# 管理画面仕様

## 概要

- 管理者は、サーバーに最初にログインしたアカウントとする（[login-1](./web-e2e.md)）
- 管理画面はログイン後の3カラムレイアウトの中央カラムに出す
  - 左カラムの「サーバー」に、管理者にだけ「招待コード」と「ジョブキュー」を出す
  - 登録ユーザーの一覧は「メンバー」（[UI仕様](./web-ui.md)）で見るため、管理画面には置かない
- 管理者でないユーザーが管理画面のURLを開いた場合は403エラーを出す

## 画面

### 招待コード（`/admin/invite-codes`）

- 招待コードを新しい順に一覧で出す。下までスクロールすると続きを読み込む
  - 列：コード、状態（未使用・使用済み・期限切れ）、使用者、有効期限、作成日
- 「新規作成」で有効期限7日の招待コードを作り、一覧の先頭に出す
- 未使用の招待コードは削除できる。期限切れでないものは削除前に確認する
- データの取得は loader、作成・削除は action で行う

### ジョブキュー（`/admin/bull-board`）

- bull-board の画面をそのまま出す（3カラムレイアウトの外）

## XRPC API

### me.subsco.admin.verifyAccess

管理画面へのアクセス権を検証し、サーバーの状態とユーザーの権限を返す。

#### 権限

- ログイン済みであれば誰でも呼び出し可能

#### リクエスト

なし

#### レスポンス

| フィールド | 型                                             | 説明         |
| ---------- | ---------------------------------------------- | ------------ |
| status     | "needsSetup" \| "authorized" \| "unauthorized" | アクセス状態 |

- `needsSetup`: 管理者が未登録（初期セットアップが必要）
- `authorized`: 管理画面にアクセス可能
- `unauthorized`: 管理者ではないためアクセス不可

#### エラー

| ステータス | 説明                            |
| ---------- | ------------------------------- |
| 401        | 未ログイン（AuthRequiredError） |

### me.subsco.admin.registerAdmin

初回セットアップ時に管理者を登録する。

#### 権限

- ログイン済みかつ管理者が存在しない場合のみ呼び出し可能

#### リクエスト

なし（ログイン済みユーザーのDIDを自動的に使用）

#### レスポンス

なし

#### エラー

| ステータス | 説明                                            |
| ---------- | ----------------------------------------------- |
| 400        | 既に管理者が存在する（AdminAlreadyExists）      |
| 400        | リクエストユーザーが存在しない（ActorNotFound） |
