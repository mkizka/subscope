# Web E2E仕様

Webクライアントをブラウザから操作したときの振る舞いを定める。

- 各項目にはIDを振り、E2Eテスト（`apps/web/e2e`）はテスト名の先頭にIDを書いてその項目を検証する
  - 例: `test("login-1: 最初にログインしたアカウントが管理者として登録される")`
- 仕様の追加・変更は、この文書を先に更新してからテストと実装を変更する

## ログイン

atprotoアカウントでOAuthログインする。

- login-1: 最初にログインしたアカウントが管理者として登録される

## 管理画面

管理者が招待コードを管理する。

- admin-1: 管理者は左カラムの「招待コード」から招待コードの一覧を開ける
- admin-2: 招待コードを作成すると一覧の先頭に追加される
- admin-3: 未使用の招待コードを削除すると一覧から消える
